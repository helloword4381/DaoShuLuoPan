3. **判定标准**：`apksigner` **exit code = 0** 且输出含 `Verifies`，并且 **v2 或 v3 至少一项为 `true`**。
4. **本地产物的签名者是本地测试密钥**：DN = `CN=DaoShu Compass Test, OU=Local Verify, O=DSH, L=Local, ST=Local, C=CN`，对应仓库根目录 `release-key.jks`（2,266 字节，已被 `.gitignore` 排除）。**发布包必须由 GitHub Secrets 中的正式密钥重新签名**（R-11）。
